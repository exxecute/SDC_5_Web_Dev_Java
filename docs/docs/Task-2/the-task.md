# The task

Spring Server Playground

## Objective

Set up a basic Spring MVC application and understand the request handling flow.

## Tasks

1. Add Spring Web dependency to the project
2. Configure Spring to work with embedded Tomcat
3. Create a welcome controller with a simple endpoint
4. Create a controller that returns a list of items (beverages, currencies, etc.)
5. Start and stop the application, observe the server behavior
6. Make a request to your endpoint using a browser or Postman

## Deliverables

- Running Spring MVC application with embedded Tomcat
- At least two working endpoints

## Acceptance Criteria

- Application starts on configured port (default 8080)
- Endpoints return expected responses
- Application stops gracefully

## Extra Tasks

- Use a service layer to provide data to the controller
- Serialize response to JSON
